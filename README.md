# Stove Daily Companion

현재 버전: **1.0.4**

스토브 출석·미션 보상 수령과 **현재 탭의 캡슐 뽑기**를 동시에 진행하는 Tampermonkey 유저 스크립트입니다.

## 설치

1. 같은 STOVE 페이지에서 동작하는 다른 자동화 스크립트는 비활성화합니다.
2. [스크립트 설치](https://raw.githubusercontent.com/mihile/stove-daily-companion/main/stove-daily-companion.user.js)를 열어 설치합니다. 설치 화면이 열리지 않으면 Tampermonkey 새 스크립트에 파일 전체를 붙여 넣고 저장합니다.
3. 런처에서 로그인 후 연 [로스트아크 공지사항](https://lostark.game.onstove.com/News/Notice/List)을 새로고침합니다. [캡슐 뽑기 페이지](https://reward.onstove.com/ko/event)에서도 시작할 수 있습니다.
4. 금액을 선택하고 **일일 보상 한 번에 받기**를 누릅니다.

페이지를 열 때 기본 선택은 항상 **100 플레이크**입니다. 선택한 버튼에는 체크 표시가 붙고 밝은 배경과 어두운 글씨로 표시됩니다. 1,000 플레이크 또는 뽑기 안 함으로 바꿀 수 있습니다.

## 처리 순서

출석 작업·미션 묶음·현재 탭의 캡슐 뽑기를 동시에 시작합니다. 마작일번가 출석과 스토어 출석은 순서대로 처리하며, 모든 작업이 끝나야 전체 처리가 종료됩니다. 미션 5개는 한 탭에서 순서대로 수령합니다. 방문 후 상태가 바로 갱신되지 않는 항목은 모아서 한 번만 새로고침합니다.

미션 페이지와 출석 페이지 로딩은 동시에 진행합니다. 동시 요청을 줄이기 위해 마작일번가·스토어 출석 수령만 순서대로 처리하고, 미션 수령은 별도로 진행합니다.

이미 다른 탭에서 실행 중일 때 버튼을 다시 눌러도 새 탭을 만들지 않으며, 현재 실행 중이라는 안내를 표시합니다.

항목이 실패하면 상태 자리에 **재시도** 버튼이 표시됩니다. 이 버튼은 전체 작업을 반복하지 않고 실패한 항목만 다시 처리합니다. 성공하면 완료됨으로 바뀌고, 다시 실패하면 오류 내용과 재시도 버튼을 유지합니다.

- 앞의 일일 보상은 별도 작업 탭에서 확인합니다. 확인이 필요한 탭은 남겨 둡니다.
- **공지사항에서 시작하면:** 선택 금액과 실행 요청을 새 뽑기 탭으로 전달하고 그 탭을 활성화합니다. 새 탭에서 일일 보상 처리와 뽑기를 동시에 진행합니다. 기존 뽑기 탭을 미리 열어 둘 필요가 없습니다. 공지사항 탭은 그대로 남습니다.
- **뽑기 페이지에서 시작하면:** 그 탭에서 출석·미션 수령과 동시에 뽑기를 진행합니다. 미션 페이지에서 시작하면 같은 탭을 뽑기 페이지로 이동한 뒤 처리합니다.
- 로그인은 해당 브라우저의 기존 스토브 세션을 사용합니다. 런처·웹사이트의 로그인 상태가 다른 경우 웹사이트에서 로그인을 완료해야 합니다.
- 출석 URL 끝의 연월은 **Asia/Seoul 기준 현재 날짜**에서 매번 계산합니다. 예를 들어 2026년 9월에는 `202609`, 10월에는 `202610`, 2027년 1월에는 `202701`입니다. URL을 매월 수정할 필요가 없습니다. 해당 월의 이벤트가 실제로 열려 있어야 합니다.
- 출석 이벤트 페이지에서는 패널의 안내대로 뽑기 페이지를 열어 실행합니다.
- 오늘 날짜 출석 카드의 ‘완료’, 미션의 ‘받기 완료’, 뽑기의 ‘30/30회’를 확인하면 클릭 없이 넘깁니다.
- 뽑기는 오늘 총 30회까지만 합니다. 이미 10회 했다면 20회만 실행합니다.
- **상태만 스캔**은 보상을 수령하거나 뽑기를 진행하지 않습니다.
- 앱 로그인·게임 플레이 등의 참여 조건은 사이트에서 충족되어 있어야 합니다.
- 실행 중에는 현재 탭을 유지하고, 다른 탭에서 수동 뽑기를 동시에 진행하지 마세요.

## 뽑기 기록

패널에 실행별 사용 플레이크, 획득 플레이크, 순이득, 상품·쿠폰 이름과 회차별 결과가 표시됩니다. 마지막 당첨 결과 창은 그대로 남깁니다.

- 사이트의 참여 횟수가 정확히 1회 증가하면 선택한 금액을 사용량으로 기록합니다.
- 새 당첨 결과 창에서 ‘숫자 + 플레이크’를 읽어 획득량으로 기록합니다. 상품·쿠폰·포인트는 이름 그대로 저장하고 플레이크로 환산하지 않습니다.
- 같은 결과가 연속으로 나와도 회차별로 기록합니다.
- 횟수 또는 보상 확인에 실패하면 추가 뽑기를 멈추고 미확인 상태를 남깁니다. 미확인 값을 합계에 추측해서 넣지 않습니다.
- 최신 100개 실행 기록을 유저 스크립트 저장소에 보관합니다. ‘기록 JSON 저장’으로 전체 보관 기록을 내려받을 수 있습니다.
- 기록은 이 브라우저의 스크립트 설치 단위이며 **계정별로 분리하지 않습니다**. 실행 시각은 한국 시간으로 표시됩니다.
- 이 버전으로 실행한 자동 뽑기부터 기록합니다. 이전 버전·수동 뽑기의 과거 결과나 일일 출석 수령액은 뽑기 합계에 포함하지 않습니다.
- 새로고침·중단 직전에 전송된 요청은 취소되지 않습니다. 결과를 확인하지 못한 회차는 미확인으로 남습니다.

## 개발 및 검증

Node.js와 npm이 필요합니다.

```sh
npm install
npm test
```

31개 DOM 기반 검사: 100/1000 팝업 연속 뽑기, 동일 결과 반복 기록, 한번 더 회차 미증가 및 비활성 버튼 처리, 출석 직렬·미션·뽑기 동시 처리와 전체 완료 대기, 동시 작업 중단·실패 후 다른 작업 완료 대기, 미션 수령 직렬화, 묶음 새로고침 및 완료 항목 재처리 방지, 공지사항 새 탭 실행·중복 탭 방지·금액 전달, 일회성 요청 소비, 만료 요청 거부, 한국 시간 월말·연말 전환, 기본 선택/대비, 실패 항목 개별 재시도, 현재 탭 실행, 남은 횟수, 소비·획득 집계, 연속 동일 당첨, 상품 이름, 응답 미확인 시 중단, 완료 건너뛰기, 날짜별 출석, 읽기 전용 스캔, 내부 팝업 닫기, 보상 금액 파싱.

2026-09-06 사용자가 시작한 실계정 실행을 관찰했습니다. 전체 약 67초, 8개 중 7개 완료였으며 스토어 출석은 사이트의 일시 오류로 남았습니다. 뽑기 30회는 약 40초, 기록 간격은 평균 1.28초였습니다. 이후 방문 대기와 상태 확인 간격을 단축했으며 최종 수정본의 실제 단축 시간은 아직 측정하지 않았습니다.

## 라이선스

MIT 라이선스로 배포합니다.

STOVE의 공식 도구가 아니며 사이트의 버튼·DOM 변경에 따라 수정이 필요할 수 있습니다. 비공개 API나 로그인 토큰을 수집하지 않습니다.


## 연속 뽑기 개선

같은 금액의 '한번 더!' 버튼이 있으면 결과 팝업을 닫지 않고 이어서 뽑습니다. 서버 회차가 정확히 1회 증가하고 결과 표시가 250ms 이상 안정된 후 기록합니다. 이전 회차와 같은 보상도 별개 회차로 기록합니다. 요청 후 회차가 늘지 않거나 버튼이 비활성화되어 있으면 추가 클릭을 하지 않습니다.

2026-09-06 사용자 수동 클릭 관찰에서 5/30 → 15/30을 확인했습니다. 연속 관측된 12→15회 구간의 결과 갱신 간격은 약 1.29초, 1.18초, 1.26초였습니다. 팝업은 유지되었고 동일 보상이 연속 표시되는 경우도 확인했습니다. 이는 수동 관찰값이며 수정 스크립트의 실계정 속도 측정값은 아닙니다.

## 접기 및 오류 재확인

350px 너비의 2열 패널입니다. 접으면 실행 버튼과 펼치기 버튼만 표시되며 접힌 상태에서도 실행됩니다. 접기 상태를 기억합니다. 진행 확인·중단은 펼친 패널에서 가능합니다.

출석 일시 오류가 발생하면 한 번 새로고침해 완료 여부를 재확인합니다. 완료되지 않았다면 확인 필요로 남깁니다.

## 자동 업데이트

`@updateURL`과 `@downloadURL`은 이 저장소의 main 브랜치를 가리킵니다. Tampermonkey 업데이트 설정에 따라 새 버전을 확인합니다. 기존 직접 붙여넣기 사용자는 이 배포본으로 한 번 교체하세요.

후속 배포 시 `@version`을 올리고 같은 경로에 게시합니다. 패널 표시 버전, package.json, README도 함께 갱신하세요.
