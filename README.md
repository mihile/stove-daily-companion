# Stove Daily Companion

현재 버전: **1.0.5**

스토브 출석·미션 보상과 플레이크 뽑기를 한 번에 처리합니다.

## 설치 및 사용법

1. 크롬에 [Tampermonkey](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo)를 설치합니다.
2. 크롬 확장 프로그램 목록 → Tampermonkey → **세부정보**에서 **사용자 스크립트 허용**을 켭니다.
3. [스크립트 설치](https://raw.githubusercontent.com/mihile/stove-daily-companion/main/stove-daily-companion.user.js)를 누르고, 열린 화면에서 **설치**를 누릅니다.
4. 스토브 런처에 로그인한 뒤 로스트아크를 선택하고, 공지사항 옆 **전체보기**를 눌러 [공지사항 페이지](https://lostark.game.onstove.com/News/Notice/List)를 엽니다.
5. 페이지를 새로고침하고 왼쪽 아래에서 뽑기 금액을 선택한 뒤 **일일 보상 한 번에 받기**를 누릅니다.

## 알아두세요

- 처음에는 **100플레이크 뽑기**가 선택됩니다. 변경한 선택은 같은 브라우저에서 다음 날에도 유지됩니다. **뽑기 안 함**도 선택할 수 있습니다.
- 공지사항에서 시작하면 새 뽑기 탭이 열리고, 뽑기와 출석·미션 수령이 동시에 진행됩니다. 실행 중에는 탭을 닫지 마세요.
- 이미 받은 보상은 건너뛰고, 뽑기는 오늘 총 **30회**까지만 진행합니다. 출석 링크는 매월 자동으로 바뀝니다.
- 실패한 항목은 작업이 끝난 뒤 **재시도**를 눌러 다시 받을 수 있습니다. **상태만 스캔**은 수령 없이 상태만 확인합니다.
- 앱 로그인·게임 플레이 조건은 직접 충족해야 합니다.
- 창을 접어도 실행할 수 있습니다. 진행 상황 확인과 중단은 펼쳐서 이용하세요.

## 뽑기 기록

사용·획득 플레이크, **순이득**, 당첨 상품을 확인할 수 있습니다. 기록은 같은 브라우저에 저장되며 계정별로 구분되지 않습니다. 수동 뽑기와 출석 보상은 포함되지 않습니다.

## 업데이트

Tampermonkey의 자동 업데이트가 켜져 있으면 새 버전으로 업데이트됩니다. 바로 업데이트하려면 위의 **스크립트 설치** 링크를 다시 누르세요.
